# אתר תרומות למפוני בתים - פרויקט נתיב

## על הפרויקט
אתר לאיסוף תרומות למשפחות שנפגעו במלחמה ונאלצו לעזוב את בתיהן.
פרויקט סוף שנה - כיתה ח׳

## קבצים
- `index.html` - הדף הראשי של האתר
- `style.css` - עיצוב ואנימציות
- `script.js` - פונקציונליות ואינטראקטיביות
- `README.md` - הסבר על הפרויקט

## תכונות
✅ עיצוב רספונסיבי (מתאים לנייד ומחשב)
✅ טופס תרומה אינטראקטיבי
✅ סטטיסטיקות בזמן אמת
✅ אנימציות ואפקטים ויזואליים
✅ תמיכה בעברית (RTL)

## הרצה מקומית
פתחו את `index.html` בדפדפן כלשהו

## טכנולוגיות
- HTML5
- CSS3 (Grid, Flexbox, Animations)
- JavaScript (ES6+)

## כיצד זה עובד
1. המשתמש בוחר סכום תרומה
2. ממלא פרטים אישיים
3. לוחץ "תרום עכשיו"
4. מקבל אישור והנתונים מתעדכנים
